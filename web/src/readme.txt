무드 컨덕터 — 내 컴퓨터에서 AI 가 실시간으로 배경음악을 만드는 HTML
================================================================

■ 여는 법
  1. car_bgm_player.html 을 노트북에 내려받습니다 (파일 하나, 약 24MB).
  2. 더블클릭 → 크롬 또는 엣지로 열립니다. (다른 브라우저로 열리면: 오른쪽 클릭 → 연결 프로그램 → Chrome/Edge)
  3. 가운데 초록 ▶ 를 누르면 악기 소리·AI 모델을 올린 뒤 바로 연주가 시작됩니다 (처음 1~3초).
  인터넷 연결은 필요 없습니다. 설치도 없습니다. 모든 계산이 노트북 안에서 일어납니다.

■ 버튼
  · 상황 9개 (아이 재우기 · 진정 · 위로 · 즐거운 대화 · 바닷가 · 비 오는 길 · 자연 속 · 드라이브 · 기본)
      누르면 "다음 마디부터" 그 분위기로 바뀝니다. 앞 마디를 이어받아 곡이 끊기지 않고 넘어갑니다.
      상황마다 볼륨도 같이 조절됩니다 (예: 아이 재우기 −8dB).
  · 📞 통화 중 : 누르는 즉시 음악을 크게 줄이고, 다시 누르면 천천히 돌아옵니다.
  · 🔊 : 전체 볼륨
  · 세부 조절 (PC 화면에선 오른쪽에 늘 펼쳐짐)
      빠르기(BPM) · 음 밀도(성기게↔빽빽하게) · 겹친 음(한 줄 선율↔두꺼운 화음) · 음역(낮게↔높게)
      창의성(낮으면 무난, 높으면 모험적) · 장조/단조 · 박자 · 악기 켜고 끄기
      바꾸면 0.5초 뒤 다음 마디부터 반영됩니다 ("직접 조절" 로 표시).
  · ⓘ : 모델 정보와 지금 AI 에 들어가는 조건 낱말
  · ◐ : 밝은 화면 / 어두운 화면

■ 화면 아래 숫자
  "AI 엔진 WASM · 초당 N낱말 · 앞으로 X초 준비됨"
  · 초당 낱말이 60 이상이면 빽빽한 곡(즐거운 대화)도 끊기지 않습니다. (DGX 에서 크롬 실측 150~230)
  · "앞으로 X초" 가 0 근처로 자주 떨어지면 노트북이 바쁜 것입니다 → 창의성은 그대로 두고 음 밀도를 낮추거나
    다른 무거운 프로그램을 닫아 주세요.

■ 안에 들어 있는 것
  · 음악 모델: 직접 만든 1,430만 파라미터 디코더 (d384 · 8층, int8 로 줄임). 공개 악보 PDMX
    (퍼블릭 도메인·CC0) 9.7만 곡을 "악보 낱말" 로 학습해 한 마디씩 직접 씁니다. 문법 막기로 깨진 악보는 안 나옵니다.
  · 계산: C 로 짠 WebAssembly SIMD 엔진 (안 되는 브라우저에선 자바스크립트 엔진으로 자동 전환).
  · 악기 소리: MuseScore General 사운드폰트(MIT) 에서 11 악기 + 드럼을 떠서 넣었습니다.

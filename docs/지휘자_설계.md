# 지휘자 — 상황을 보고 AI 가 알아서 (11-13)

슬라이더를 사람이 만지는 대신, 차가 아는 상황(여정 · 요일 · 시간대 · 날씨 · 장소 · 달리기 · 누구랑 · 차 안 소리 · 말)을 받아
**무슨 분위기를, 어떤 악기로, 얼마나 빠르고 세게, 얼마나 크게** 를 지휘자가 정합니다.
악보는 그대로 화음 AI · 선율 AI 가 씁니다. 지휘자는 그 AI 에게 "무엇을" 을 정해 주는 첫 겹입니다.

```
상황 JSON ──▶ 지휘자 (data/conductor/*.json 규칙 · 장면)
              │  분위기 · 조절값 7개 · 악기 지시 · 주변 소리 · 섞기
              ▼
           엔진 (화음 AI → 선율 AI → 편곡 → 연주)  ──▶  스피커
              ▲
   실내 마이크 말소리 크기 (0.1초마다) ── 섞기: 전체 줄임 · 말 대역 비우기 · 말과 겹치는 악기 줄임
```

- 코드: `engine/src/conductor.cpp` (정하기) · `engine/src/json.cpp` (작은 JSON) · `engine/src/engine.cpp` `cond_tick` (언제 바꾸나) · `render` (섞기)
- 자료: `engine/data/conductor/` — 글자 파일이라 다시 빌드하지 않고 고칠 수 있음
- 시험: `engine/scenarios/*.json` 운전 대본 4개 → `engine_cli scenario` 가 소리 + 기록을 만듦


## 1. 상황 어휘 — `signals.json` (11갈래 · 84가지)

| 갈래 | 칸 | 가짓수 | 실제 차에선 |
|---|---|---|---|
| 여정 | `trip.kind` | 8 (출근 · 퇴근 · 등하원 · 나들이 · 장거리 · 심야 귀가 · 급한 이동 · 드라이브) | 내비 목적지 · 날마다 같은 길 |
| 시간대 | `time.slot` | 7 | 차 시계 (안 보내면 지휘자가 채움) |
| 요일 | `time.group` | 5 (월 · 주중 · 금 · 주말 · 연휴) | 차 시계 · 공휴일 |
| 날씨 | `weather.kind` | 10 | 날씨 API · 와이퍼 · 바깥 온도 |
| 장소 | `place.kind` | 11 (+ `place.ahead` 앞에 터널 몇 초) | GPS · 내비 지도 |
| 달리기 | `drive.state` | 9 (또는 `speed` · `limit` 만 보내면 지휘자가 정함) | 차량 SDK |
| 차 상태 | `car.*` | 창문 · 길 안내 음성 · 운전 시간 · 시동 직후 | 차량 SDK |
| 동승자 | `people.*` | 무리 6 · 아기(깸 · 잠 · 울음) · 반려동물 | 좌석 센서 · 실내 카메라 · 한 번 고름 |
| 차 안 소리 | `cabin.sound` + `cabin.talk` | 8 + 말소리 크기 0~1 | 실내 마이크 (우리 음악을 뺀 소리) |
| 말 | `/api/say` | 요청 10가지 (`speech_words` 낱말) | 음성 인식 문장 |
| 운전자 | `driver.state` | 졸음 · 짜증 · 피곤 (보내지 않으면 추정) | 운전 시간 · 하품 · 시간대 · 언성 |

보낼 땐 아는 것만, 바뀐 것만 보내면 됩니다. `null` 은 그 칸을 지웁니다.

```json
POST /api/situation
{ "trip": {"kind": "commute"}, "weather": {"kind": "rain"}, "place": {"kind": "city", "ahead": [{"kind": "tunnel", "in_sec": 40}]},
  "drive": {"speed": 62, "limit": 60}, "people": {"group": "alone"}, "car": {"windows": "closed"}, "cabin": {"sound": "quiet", "talk": 0.1} }
```


## 2. 조합 — 평균으로 뭉개지지 않게

상황이 여러 개 겹칠 때 전부 더해 평균을 내면 늘 "무난한 중간" 이 됩니다. 그래서 **갈래마다 음악의 다른 면을 맡깁니다.**

- **바탕 base** (여정): 장르 · 기운의 출발점 — 하나만 이김
- **결 tone** (시간대 · 요일 · 운전자): 빠르기 · 밝기를 조금씩 — 더함
- **색 color** (날씨): 화음 · 음색 · 주변 소리
- **공간 space** (장소): 울림 · 음역 · 터널 비우기
- **지킴 care** (아기 · 안전 · 과속): 뚜껑 — 빠르기 상한 · 기운 상한 · 밝기 상한 · 드럼 · 금관 금지 (여럿이면 **가장 낮은 것**)
- **움직임 motion** (달리기): 정체 달래기 · 출발 · 도착 임박 끝맺기
- **섞기 mix** (차 안 소리): 크기 · 말 대역 · 말과 겹치는 악기

합치는 법도 갈래마다 다릅니다.

- 뚜껑은 **가장 작은 값** (아기 잠 72bpm 과 과속 100bpm 이 겹치면 72)
- 주변 소리(파도 · 비)는 **우선순위가 가장 높은 규칙** 것
- 악기 선호는 **더함**, 악기 성격표(`instruments.json`)의 떠올림 낱말(`evokes`)이 맞으면 덤
- 분위기 점수: 갈래 무게 + 규칙이 민 분위기 + 기운 · 밝기 거리 + 떠올림 + (지금 것 유지 덤) − (최근에 들은 것) − (금지 · 뚜껑 넘김)

**장면** (`scenes.json` 32개) 은 뜻 있는 조합 자체에 고유한 색을 줍니다.
"비 + 월요일 + 출근" 은 각 규칙을 더한 것과 다른 "촉촉하지만 처지지 않게" 라는 장면 하나로 잡습니다.
맞은 칸이 가장 많은 장면이 이기고, 장면이 있으면 바탕은 장면이 정합니다.

조합 규칙 예 (`rules.json`):

- 바닷가 + 창문 닫힘 → 실제 파도 소리를 작게 (`mix.coast_closed`)
- 비 + 창문 닫힘 → 빗소리 0.8
- 젖은 길 + 과속 → 몇 분에 걸쳐 더 차분하게
- 아기 + 터널 → 비우되 너무 얇게는 안 (`thin: false`)
- 터널 40초 전 → 미리 가볍게 · 터널 나와서 40초 → 활짝
- 도착 0.6분 전 → 끝맺음

## 3. 규칙 한 줄의 꼴 — `rules.json` (94개)

```json
{ "id": "people.baby_sleeping", "when": { "people.baby": "sleeping" }, "aspect": "care", "priority": 90,
  "hold_sec": 2, "release_sec": 4, "say": "아기가 자요 → 잔잔하게",
  "set": { "job": "달래기", "energy": -30, "bright": 4, "genre": { "song": 1.5 },
           "caps": { "tempo_max": 72, "energy_max": 25, "bright_max": 68, "drums": false, "brass": false, "volume_db": -6, "rear_db": -12 },
           "moods": { "아이재우기": 1.4, "진정": 0.6 }, "baby_only": true, "move": "slow" } }
```

- `when`: 칸 → 값 · `[값들]` · `{"not": …}` · `{"gt": n}` · `{"lt": n}` — 전부 맞아야 켜짐
- `hold_sec`: 이만큼 이어져야 켜짐 (잠깐 스친 상황에 흔들리지 않게) · `release_sec`: 조건이 꺼져도 이만큼 더 (아기 잠 → 울음 사이 튐 막기)
- `set`: `energy` · `bright` (더함) · `tempo` · `dens` · `tension` · `novelty` · `space` · `moods` · `avoid_moods` · `instr` · `avoid_instr` · `evokes` · `genre` · `caps` · `ambience` · `volume_db` · `duck_db` · `talk_duck_db` · `talk_cut_db` · `overlap_db` · `lead_rest` · `thin` · `move` · `end` · `baby_only`

뚜껑(`energy_max` 등)이 있으면 고른 분위기보다 세게 · 촘촘하게는 가지 않습니다. 밝기 · 기운은 80 위로는 부드럽게 눌러, 여럿이 더해져도 끝까지 치솟지 않습니다.


## 4. 언제 바꾸나 — 엔진 쪽 (`cond_tick`, 0.5초마다)

- 분위기를 바꾸려면 새 결정이 **8초** 이어져야 하고, 지금 분위기에서 **45초** 는 머뭄 (급한 일 — 아기 · 언성 · 과속 — 은 3초 · 8초)
- "이거 좋다" 뒤엔 10분 머뭄 · 사람이 직접 고른 분위기는 15분 지킴 · "다른 거" 는 그 분위기를 10분 안 고름
- 같은 분위기 안에서 조절값 · 악기 지시가 꽤 달라지면 15초 간격으로 반영 (터널 · 급한 일 · 큰 변화는 2초) → 다음 프레이즈 끝에서 AI 가 다시 씀
- 시작은 상황이 자리 잡을 3.6초를 기다렸다가 (장면은 3초 이어져야 켜짐)

## 5. 말소리 섞기 — 실시간

말소리 크기(`cabin.talk`, 0~1, 마이크에서 0.1초마다)를 받아 소리 줄에서 바로:

- 전체를 `talk_duck_db` 만큼 (대화 −3dB · 언성 −6dB · 통화 −15dB)
- 1.5kHz 둘레 말 대역을 `talk_cut_db` 만큼 파냄 (peaking EQ, Q 0.6)
- 말과 겹치는 악기(성격표 `talk` 값이 큰 색소폰 · 트럼펫 · 바이올린 …)는 더 줄임
- 오르내림: 0.15초에 내려가고 · 3초 머물고 · 1.5초에 돌아옴 (말 사이 숨에 음악이 들썩이지 않게)
- 대화가 이어지면(`cabin.sound: talk`) 규칙 쪽에서 선율 악기를 쉬게 하고 반주만 (`lead_rest`)

마이크 값이 없으면 `cabin.sound` 로 대신합니다 (대화 · 언성 = 1, 웃음 = 0.7).
화면의 [🎙 차 안 말소리 듣기] 는 노트북 마이크로 이것을 흉내 냅니다 — 스피커로 나가는 우리 음악 크기(`/api/level`)만큼은 빼고 듣습니다.


## 6. API

- `POST /api/situation` 상황 일부 · `GET /api/situation` 지금 상황 (지휘자가 채운 칸 포함) · `POST /api/situation/reset`
- `POST /api/say {"text": "아기 잔다"}` → `{"intent": "baby_sleep", "say": "아기가 자요 → 잔잔하게 바꿀게요"}`
- `POST /api/auto {"on": 1}` 알아서 · `{"on": 0}` 직접 · `{"start": 1}` 지휘자가 고른 분위기로 시작
- `GET /api/decision` 지금 결정 전체 (분위기 순위 · 켜진 규칙 · 악기 지시 · 섞기)
- `GET /api/level` 지금 나가는 소리 크기 (마이크 메아리 빼기용)
- `GET /api/state` 에 `auto` · `talk` · `dec {line, scene, because, next}` 가 붙음

## 7. 운전 대본으로 시험 — `engine_cli scenario`

```
CAR_BGM_SEED=42 ./build/engine_cli scenario data out.wav scenarios/01_비오는월요일_출근.json out.txt
```

대본은 `{"t": 초, "set": 상황 | "say": 말 | "talk": 0~1 | "end": true}` 의 줄. 기록에 결정이 바뀔 때마다 이유 · 악기 · 뺀 악기 · 뚜껑이 찍힙니다.
결과(11-13, 새 선율 AI mel_S2): `dist/샘플/상황데모/` mp3 + 기록 txt.

- 01 비 오는 월요일 출근: 평온한 재즈 → 30초 정체에 달래기 → 터널 40초 전 미리 가볍게 → 터널 안 선율 쉼(말 대역 −16.5 → −20.7dB) → 출구에서 활짝 → 통화 −15dB (−18 → −34dB) → 도착 앞 끝맺음
- 02 주말 가족 바닷길: 상쾌한 아침 → 해안도로 장면 바닷가 보사노바 + 파도 → 대화 중 선율 비움 → "이제 애기 재우자" → 아이 재우기(72bpm · 드럼 · 금관 빼기 · −6dB) → 울음 ↔ 잠 바뀌어도 튀지 않음
- 03 금요일 밤 둘이 · 비: 서브톤 색소폰 발라드(비 오는 날) → 대화 → 언성(−6dB · 선율 쉼 · 낮고 부드럽게) → 바닷가 + 파도 → "이거 좋다" 10분 유지
- 04 심야 고속도로 혼자: 밤 고속도로(또렷하게) → 하품에 졸음 막기 → 과속에 몇 분에 걸쳐 차분하게(기운 상한 55)
